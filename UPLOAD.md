# Apps hochladen (2 Minuten)

Die großen HTML-Dateien bitte einmal manuell ins Repo legen – danach bleiben sie **dauerhaft** und du kannst GitHub Pages aktivieren.

## Schritte

1. ZIP herunterladen (siehe Chat) und entpacken  
   → `aksara-thai-letters.html` und `cybertown-ufo-shooter.html`

2. Im Browser öffnen:  
   https://github.com/DJPetraDJP/aksara-und-cybertown

3. **Add file** → **Upload files**  
   Beide HTML-Dateien hierher ziehen → **Commit changes**

4. **GitHub Pages** aktivieren:  
   **Settings** → **Pages** → Source: **Deploy from a branch**  
   Branch: **main** / folder: **/ (root)** → Save

5. Nach 1–2 Minuten erreichbar unter:  
   **https://djpetradjp.github.io/aksara-und-cybertown/**

Fertig – der Link verschwindet nicht mehr.
